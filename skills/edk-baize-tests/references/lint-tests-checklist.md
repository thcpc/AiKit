# Lint-Tests 格式检查清单

⛔ 所有检查项必须逐项执行，不可跳过。

## 测试用例格式检查

对照 `references/test_template.md` 检查：

- [ ] 文件头部包含"测试套件信息"章节
- [ ] 测试套件信息包含：功能模块、需求编号、测试目标
- [ ] 每个测试用例包含：用例编号、Priority、Method、Precondition、Test Steps、Expected Result
- [ ] Test Steps 使用编号列表格式
- [ ] Expected Result 使用列表格式
- [ ] 用例之间使用 `---` 分隔符

## 任务文档格式检查

对照 `references/test-task-template.md` 检查：

- [ ] 包含"概述"章节（XMind 文件名、生成时间）
- [ ] 包含"测试用例集清单"章节
- [ ] 清单中 checkbox 格式正确（`- [ ]` 或 `- [x]`）
- [ ] 包含"统计信息"章节（总数、各优先级数量）
- [ ] 包含"执行计划"章节（按优先级分阶段）
- [ ] 包含"测试方法分布"章节
- [ ] 包含"注意事项"章节
- [ ] 包含"相关文档"章节

- 测试用例文件完全符合 `references/test_template.md` 格式
