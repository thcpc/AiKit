# Lint 检查清单

⛔ 以下所有检查项都很重要，不可遗漏任何一项。每次 lint 必须逐项执行并报告结果。

## 脚本检查

先尝试 `python3 scripts/lint_runner.py <wiki_root> [topic]`，失败则改用 `py scripts/lint_runner.py <wiki_root> [topic]`

⛔ 检查项（全部必须执行）：
- [ ] **目录结构合规**：每个 topic 必须有标准七子目录（entities/concepts/procedures/rules/comparisons/summaries/synthesis），不能有非标准目录
- [ ] **孤立页面**：entities/、concepts/、procedures/、rules/ 下没有被其他页面引用的页面
- [ ] **断链**：`[[X]]` 链接指向的 X.md 不存在（支持 `[[X|别名]]` 语法）
- [ ] **index 一致性**：index.md 里有记录但文件缺失的条目

## AI 补充检查

⛔ 检查项（全部必须执行，不可跳过任何一项）：

- [ ] **内容拆分合理性**：
  - 概念页里出现"步骤 1 / 步骤 2 / 步骤 3" → 报错，建议拆出 procedure
  - 概念页里出现完整的状态转换表 / 决策表 → 报错，建议拆出 rule
  - 概念页 > 150 行 → 警告，提示复审
  - procedures/ 下的页面是否包含真正的步骤（缺步骤的 procedure 是错的）
  - rules/ 下的页面是否包含明确的约束/状态机/决策表（只是叙述性的不算 rule）

- [ ] **矛盾信息**：阅读相关页面，检查是否有互相矛盾的说法
  - 列出发现的矛盾
  - 标注每处矛盾的来源页面

- [ ] **交叉引用缺失**：检查相关主题的页面之间是否应该互相链接但没链
  - concept 应链向相关 procedure 和 rule
  - procedure 应链向涉及的 concept、rule、entity
  - rule 应链向被它约束的 entity 和触发它的 procedure
  - 建议添加的交叉引用清单

- [ ] **置信度报告**：统计 EXTRACTED / INFERRED / AMBIGUOUS / UNVERIFIED
  - 置信度标注位置：每个页面 frontmatter 的 `confidence` 字段
  - EXTRACTED：可回溯到原文的事实
  - INFERRED：从原文推断出的结论
  - AMBIGUOUS：原文表述模糊，难以确定含义
  - UNVERIFIED：无法在原文中找到依据
  - 高亮 AMBIGUOUS 条目，提醒用户优先验证
  - 抽查 EXTRACTED 条目，检查能否在原始素材中找到对应原文
  - 若页面缺少 `confidence` 字段 → 报错，提示补充

- [ ] **溯源来源格式检查**：
  - summaries 页：必须是 `[[raw/{subdir}/{文件名}|显示名]]` 格式（Obsidian wiki link）
  - concepts / entities / procedures / rules 页：必须是 `[[摘要页名]]` 格式
  - ⛔ 发现纯文本或相对路径 `[](../...)` 则报错

- [ ] **规范类文档结构完整性检查**（⛔ 仅当摘要页 doc_type 为"规范类"时执行）：
  - 检查摘要页的"文档结构"章节中，每个主要章节是否都有 `[[页面名]]` 链接
  - ⛔ 发现无链接的章节条目则报错，提示需要创建对应页面或补充链接
  - 检查链接指向的页面文件是否实际存在

- [ ] **培训类文档模块完整性检查**（⛔ 仅当摘要页 doc_type 为"培训类"时执行）：
  - 检查摘要页的"知识模块"章节中，每个模块是否都有 `[[页面名]]` 链接
  - 检查"学习目标"中的每项能力是否有对应的页面覆盖
  - 检查链接指向的页面文件是否实际存在

- [ ] **源文件清理检查**：确认 raw/ 以外不存在应已被移动的源文件残留

- [ ] **过时检测**：对比每个摘要页面的 updated 日期和对应 raw 素材的修改时间
  - 如果 raw 素材更新了但 wiki 没更新，标记为"可能过时"

## 输出报告格式

⛔ 报告必须逐项列出每个检查项的结果（✅ 通过 / ❌ 失败 / ⚠️ 警告），不可笼统概括。

报告包含：
- 每个检查项的逐项结果
- 目录结构问题（缺失/多余子目录）
- 孤立页面及建议链接
- 断链及建议创建
- 内容拆分问题及拆分建议
- 矛盾信息及来源
- 缺失索引条目
- 溯源来源格式错误清单
- 文档结构/知识模块链接缺失清单
- 置信度统计
- 过时页面清单

输出中文报告，询问用户是否自动修复。
